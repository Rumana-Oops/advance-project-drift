# Pancreatic Cancer Segmentation and Risk Assessment

## Project Overview
This research project investigates deep-learning methods for pancreatic structure and tumor segmentation using CT images.

## Dataset
- Source: Kaggle — Advance Project, Task07_Pancreas
- Contains CT images and segmentation labels.
- Dataset access and usage are subject to the original dataset's terms.

## Methods
- MONAI 3D U-Net baseline
- nnU-Net comparison (planned)
- Segmentation evaluation using Dice score
- Radiomics and downstream risk assessment (future work, subject to data availability)

## Environment
Python, PyTorch, MONAI, NumPy, pandas, and nibabel.

## Current Status
Initial dataset inspection and baseline segmentation experiments. Validation performance and segmentation quality require further evaluation.

## Reproducibility
The dataset must be accessed separately through Kaggle. Large datasets, model checkpoints, and sensitive information are not stored in this repository.
